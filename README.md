# Observation-Specific Uncertainty Modeling for Latent-Variable Regression in High-Dimensional Analytical Data

This repository contains the MATLAB code, Raman data, derived analysis results, figure files, and table files supporting the manuscript named above.

## Repository contents

- `code/`
  - MATLAB scripts for importing and preprocessing data, creating data splits, fitting partial least-squares and Gaussian-process models, and performing the reported analyses.
  - Reusable functions are stored in `code/functions/`.
- `data/`
  - `Raman/` contains the raw and processed Raman spectra, reference values, reproducible data splits, fitted models, and analysis results.
  - `AqSolDB/` contains reproducible split assignments and derived model and analysis results. The original third-party AqSolDB dataset is not distributed in this repository and must be downloaded separately as described below.
- `figures/`
  - MATLAB figure-generation scripts, raw MATLAB exports, and final figure files for the main and supplementary figures.
- `tables/`
  - MATLAB table-generation scripts and exported table values.

Detailed documentation is provided in the `README.txt` file within each main folder and dataset subfolder.

## System requirements

- MATLAB R2022a or later
- Statistics and Machine Learning Toolbox
- Optimization Toolbox

No separate installation or compilation of the custom MATLAB functions is required.

## Third-party AqSolDB dataset

The original AqSolDB dataset is not included in this repository. Download `curated-solubility-dataset.csv` from the [Harvard Dataverse record](https://doi.org/10.7910/DVN/OVHAW8) and place it at:

```text
data/AqSolDB/raw_data/curated-solubility-dataset.csv
```

The dataset should be cited as:

> Sorkun, M. C., Khetan, A. & Er, S. *AqSolDB: A curated reference set of aqueous solubility and 2D descriptors for a diverse set of compounds.* Harvard Dataverse (2019). https://doi.org/10.7910/DVN/OVHAW8

Users must comply with the licence and terms associated with the original AqSolDB record.

## Reproducing the Raman analysis

Set the MATLAB current folder to the repository root and run the following scripts in order:

```matlab
run('code/Raman/read_raw_data.m')
run('code/Raman/preprocess_data.m')
run('code/Raman/select_data_for_analysis.m')
run('code/Raman/PLSmodel.m')
run('code/Raman/GPmodel.m')
run('code/Raman/bias_correction_analysis.m')
run('code/Raman/analyte_detection_analysis.m')
```

## Reproducing the AqSolDB analysis

After downloading AqSolDB to the location specified above, set the MATLAB current folder to the repository root and run the following scripts in order:

```matlab
run('code/AqSolDB/load_AqSolDB.m')
run('code/AqSolDB/split_AqSolDB_data.m')
run('code/AqSolDB/PLSmodel_AqSolDB.m')
run('code/AqSolDB/GPmodel_AqSolDB.m')
run('code/AqSolDB/bias_correction_analysis_AqSolDB.m')
run('code/AqSolDB/uncertainty_evaluation_AqSolDB.m')
```

Fitting the heteroscedastic Gaussian-process model for AqSolDB may take substantially longer than the other analysis steps.

## Figures and tables

Figure-generating scripts are stored in the `code/` subfolder of the relevant folder under `figures/`. Table-generating scripts are stored in the `code/` subfolder of the relevant folder under `tables/`. These scripts use the saved analysis results generated by the workflows above. See `figures/README.txt` and `tables/README.txt` for output details.
