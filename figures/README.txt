README – Figures

Overview:
---------

This folder contains the main and supplementary figures for the manuscript,
together with the MATLAB scripts, raw MATLAB exports, and publication-formatted
versions used to prepare them.


Associated manuscript:
----------------------

Observation-Specific Uncertainty Modeling for Latent-Variable Regression in
High-Dimensional Analytical Data


Contents:
---------

Figure-1/ to Figure-9/
    Main manuscript figures.

Figure-S1/ to Figure-S9/
    Supplementary figures.

README.txt
    Description of the figure-directory structure, figure-generation scripts,
    source data, and output locations.


Subfolder structure:
--------------------

Each figure folder contains the relevant combination of:

code/
    MATLAB script used to generate the figure.

raw_figure/
    Initial MATLAB export before publication formatting or visual editing.

final_figure/
    Publication-formatted figure in one or more available file formats.

Figures 1 and 2 were created in Inkscape and do not have MATLAB
figure-generation scripts.

Regenerating figures:
---------------------

Set the MATLAB current folder to the project root before running a figure
script. Run the script using its relative path, for example:

    run('figures/Figure-5/code/Fig5_variance_components.m')

The required Raman or AqSolDB analysis workflow must be completed before its
dependent figure scripts are run. The workflow and execution order are
documented in:

    code/README.txt

Most figure scripts automatically create the corresponding raw_figure/ folder
when required and export an SVG file to it. The export commands are currently
disabled in the scripts for Figures 4, S1, and S3; these scripts display the
figure in MATLAB without automatically writing a new file.

Regenerating a raw figure does not update or overwrite the files in
final_figure/. Publication formatting and conversion to other file formats are
performed separately.
