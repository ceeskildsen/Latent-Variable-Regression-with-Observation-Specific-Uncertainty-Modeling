README – Data

Overview:
---------

This directory contains the datasets and model outputs used in the manuscript:

Observation-Specific Uncertainty Modeling for Latent-Variable Regression in
High-Dimensional Analytical Data

The data support two applications:

1. Raman measurements of a fructose–sucrose model system.
2. Aqueous-solubility prediction using molecular descriptors from AqSolDB.

Detailed descriptions of the files, data preparation, data splitting, and
analysis outputs are provided in the README files within each dataset folder.


Contents:
---------

data/
  - Raman/
      - raw_data/
          Raw Raman spectra, acquisition metadata, formulation information,
          and the imported MATLAB dataset.

      - processed_data/
          Preprocessed Raman spectra and associated reference information in
          MATLAB and CSV formats.

      - analysis_data/
          Calibration, validation, and test datasets, together with fitted
          models and analysis results.

  - AqSolDB/
      - raw_data/
          Download instructions for the original AqSolDB data. The
          third-party source dataset and the locally generated raw MATLAB
          file are excluded from the repository.

      - analysis_data/
          Reproducible split assignments, fitted models, and analysis
          results. The complete split dataset is generated locally and
          excluded from the repository.

      - README.txt
          Description of the AqSolDB source data, preparation, splitting, and
          analysis files.

  - README.txt
      Overview of the data directory.


Data organisation:
------------------

For the Raman application, the data are organised into three stages:

    raw_data → processed_data → analysis_data

The individual spectral acquisitions are retained as separate observations
throughout the workflow. The calibration, validation, and test assignments are
defined in the analysis-data stage.

For the AqSolDB application, the original public dataset must be downloaded
separately from https://doi.org/10.7910/DVN/OVHAW8 and placed in raw_data/.
The reproducible split assignments and derived model and analysis outputs are
stored in analysis_data/. The complete split dataset containing the AqSolDB
predictor and response values is generated locally and excluded from Git.

Related code:
-------------

The MATLAB scripts used to import, prepare, split, and analyse the datasets
are provided in:

code/Raman/
code/AqSolDB/

The scripts should be run from the project root. The appropriate execution
order and the files generated by each script are documented in the
dataset-specific README files.
