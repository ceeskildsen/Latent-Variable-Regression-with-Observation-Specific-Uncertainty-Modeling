README – Tables

Overview:
---------

This folder contains the main and supplementary tables generated for the
manuscript, together with the MATLAB scripts used to calculate and export
their contents.


Associated manuscript:
----------------------

Observation-Specific Uncertainty Modeling for Latent-Variable Regression in
High-Dimensional Analytical Data


Contents:
---------

Table-1/
    Main-text table reporting Type I and Type II analyte-detection error rates.

Table-S1/
    Supplementary table reporting the response-loading coefficients from the
    Raman partial least-squares regression model.

Table-S2/
    Supplementary table comparing uncertainty-evaluation metrics for the
    AqSolDB application.

README.txt
    Description of the table scripts, required inputs, and generated outputs.


Subfolder structure:
--------------------

Each table folder contains:

code/
    MATLAB script used to calculate and export the corresponding table.

*.txt
    Tab-delimited text file containing the exported table values.


Table 1 – Analyte-detection error rates:
----------------------------------------

Table 1 reports Type I and Type II error rates obtained using the
observation-specific Gaussian-process approach and the variance-only ordinary
least-squares approach for the two evaluated analyte samples.

Script:

    tables/Table-1/code/Table1_Type_I_II_errors.m

Required input:

    data/Raman/analysis_data/analyte_detection_results.mat

The required input is generated by:

    code/Raman/analyte_detection_analysis.m

Output:

    tables/Table-1/Table1_Type_I_II_errors.txt


Table S1 – Partial least-squares response-loading coefficients:
---------------------------------------------------------------

Table S1 reports the response-loading coefficients q1 and q2 for the two
latent variables in the Raman partial least-squares regression model.

Script:

    tables/Table-S1/code/TableS1_q_values.m

Required input:

    data/Raman/analysis_data/pls_model.mat

The required input is generated by:

    code/Raman/PLSmodel.m

Output:

    tables/Table-S1/TableS1_q_values.txt


Table S2 – AqSolDB uncertainty evaluation:
-------------------------------------------

Table S2 compares the Gaussian-process and variance-only ordinary
least-squares approaches using the mean continuous ranked probability score
and summary statistics for the estimated prediction-error variances in the
AqSolDB test set.

Script:

    tables/Table-S2/code/make_table_S2.m

Required inputs:

    data/AqSolDB/analysis_data/uncertainty_evaluation_results_AqSolDB.mat

The required inputs are generated by:

    code/AqSolDB/uncertainty_evaluation_AqSolDB.m

Output:

    tables/Table-S2/TableS2_uncertainty_summary.txt


Regenerating tables:
--------------------

Set the MATLAB current folder to the project root before running a table
script. Run the script using its relative path, for example:

    run('tables/Table-1/code/Table1_Type_I_II_errors.m')

The relevant Raman or AqSolDB analysis workflow must be completed before the
dependent table script is run. Each table script loads the required analysis
file, displays the table in MATLAB, and writes a tab-delimited text file to
the corresponding table folder.

Regenerating a table overwrites the existing text file with the same name.


System requirements:
--------------------

MATLAB R2022a or later

Required toolbox:

    Statistics and Machine Learning Toolbox

The Optimization Toolbox is also required when regenerating the fitted
Gaussian-process models used as inputs to Table S2.
